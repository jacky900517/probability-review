依原文教材節次排列的 34 張題卡（33 道不同題目）。支援搜尋、隨機複習、提示與解答、筆記、進度匯出／匯入與手機版面。

網站：https://jacky900517.github.io/probability-review/

## iPhone

以 Safari 開啟網站 → 分享 → 加入主畫面。先從主畫面圖示開啟，再匯入自己的教材包與複習進度。

顯示「題庫已可離線開啟」後可離線複習；裝置可能清理網站儲存空間，重要筆記請定期匯出。

## 私人教材

公開檔案不包含教材 PDF、原始試題截圖或上課照片。擁有原始資料的使用者可在自己的裝置匯入 `機率統計_私人教材包.json`，透過 IndexedDB 保存在本機。程式不會上傳教材包、筆記或進度。

請勿將私人教材包放進此公開儲存庫。題庫按教材章節整理，解答為推導結果，並非教授標準解答。

## 發布

GitHub Pages：Deploy from a branch → main → /(root)。使用相對路徑，可直接以靜態檔案部署。更新 app.js 或 index.html 時同步更新 sw.js 的快取版本。
