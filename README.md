## iPhone

以 Safari 開啟網站 → 分享 → 加入主畫面。教材會自動下載，不必另外匯入或傳送檔案。

顯示「題庫已可離線開啟」後可離線複習題目；另顯示「教材已儲存，可離線查看」後，原圖與課本也可離線使用。裝置可能清理網站儲存空間，重要筆記請定期匯出。

## 網站教材

依專案擁有者 2026-10-30 的要求，`materials.json.gz` 公開提供教材 PDF、原始試題截圖、上課照片與課本預覽。瀏覽器首次下載約 25 MB，解壓後驗證檔案並存入 IndexedDB，後續可離線使用；需要支援 DecompressionStream 的現代瀏覽器。下載失敗可以重試，或改用原有 JSON 匯入。

筆記和熟練進度不會上傳。題庫按教材章節整理，解答為推導結果，並非教授標準解答。
